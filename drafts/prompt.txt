Создай скрипт на Python для генерации HTML-страниц по текстовому описанию с использованием цепочки запросов (LangChain). 

**Задача скрипта:**
Пользователь вводит текстовое описание страницы (например, визитка пекарни, лендинг для стоматологии). Скрипт через цепочку из 4 этапов создаёт готовый HTML-файл с встроенными CSS-стилями, который можно открыть в браузере.

**Цепочка (4 этапа):**
1. Анализ задачи — выделяет из описания: структуру, контент, стиль, цвета.
2. Подбор инструментов — определяет нужные HTML-элементы и CSS-фичи.
3. Генерация кода — создаёт HTML-страницу с CSS.
4. Проверка — исправляет ошибки, улучшает код.

**Требования:**
- Использовать LangChain (langchain_core).
- Использовать OpenAI-клиент (или совместимый с OpenAI API, например, GenAPI).
- Все ключи и настройки загружать из `.env` (шаблон ниже).
- Скрипт должен запускаться из терминала командой `python main.py`.
- На выходе создавать папку `output/` и сохранять в ней `index.html`.
- Сохранять промежуточные данные (analysis.json, tools.json) для отладки.
- Добавить логирование (информация о каждом шаге).
- Если пользователь не передаёт описание через аргумент командной строки, использовать встроенный тестовый пример.
