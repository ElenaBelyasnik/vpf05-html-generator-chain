# Генератор HTML-страниц по текстовому описанию

Python-скрипт, который генерирует готовую HTML-страницу с встроенными CSS-стилями на основе текстового описания с помощью цепочки запросов LangChain.

## Как это работает

Скрипт проходит через 4 этапа:

1. **Анализ задачи** — выделяет из описания структуру, контент, стиль и цвета.
2. **Подбор инструментов** — определяет нужные HTML-элементы и CSS-фичи.
3. **Генерация кода** — создаёт HTML-страницу с CSS.
4. **Проверка** — исправляет ошибки и улучшает код.

## Требования

- Python 3.12+
- Ключ API от OpenAI (или совместимого провайдера)

## Установка

1. Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\Activate
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

3. Настройте переменные окружения в файле `.env` (скопируйте `.env.example`):

```
OPENAI_API_KEY=ваш_ключ
OPENAI_BASE_URL=https://proxy.gen-api.ru/v1
OPENAI_MODEL=gpt-5-6-luna
TEMPERATURE=0.2
LOG_LEVEL=INFO
```

## Запуск

### С описанием по умолчанию (тестовый пример):

```powershell
python main.py
```

### С произвольным описанием:

```powershell
python main.py --task "Описание вашей страницы"
```

### С указанием папки вывода:

```powershell
python main.py --task "Описание" --out-dir my_output
```

## Результат

Скрипт создаёт папку `output/` (или указанную через `--out-dir`) с файлами:

- `index.html` — готовая HTML-страница
- `analysis.json` — промежуточный анализ (для отладки)
- `tools.json` — подобранные компоненты (для отладки)

## Архитектура

- `main.py` — единый файл со всей логикой
- LangChain используется для построения цепочек (chains)
- OpenAI-клиент подключается через совместимый API (GenAPI и другие)
- Промпты написаны на русском языке
